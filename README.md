# Companions Forever

Public source code for **Companions Forever: Pet Battles & Adventures 1.3.3**, for WoW Forever (Interface 16001).

- [Player wiki](https://github.com/Warlune/Companions-forever/wiki)
- [Player guide](CompanionsForever/PET_GUIDE.md)
- [Changelog](CompanionsForever/RELEASE_NOTES.md)
- [Report an issue](https://github.com/Warlune/Companions-forever/issues)

This repository contains the addon runtime source and player documentation. Development tools, sandboxes, private developer commands, test data, generated reports, and addon artwork are excluded. Existing wiki illustrations are retained.

WoW model, texture, and sound paths or IDs in the Lua code refer to resources supplied by the installed game; those game assets are not bundled here.

**This is a source-only repository, not an installable addon package.** Use the packaged CurseForge release to play; the GitHub source archive intentionally omits the artwork required by the addon.
